Route your network

Edit these tables in your existing Lua file. Backends can use hostnames; listener addresses use IP addresses.

listeners = {
    public = "0.0.0.0:25565",
},
backends = {
    lobby = "127.0.0.1:25566",
    survival = "127.0.0.1:25567",
},
routes = {
    public = {
        ["play.example.com"] = "survival",
        ["*"] = "lobby",
    },
},

These are fields inside the table returned by your Lua file. Keep existing comments and hooks when making changes.

Choose what to expose

The admin and status services are optional. Keep administration on a trusted interface, and configure a token when exposing it.

web = {
    listen = "127.0.0.1:8080",
    -- Add token = "a-long-random-secret" to protect API access.
    api = true,
    ui = true,
},
status = {
    listen = "127.0.0.1:8081",
    ui = true,
    metrics = true,
},

Set web = false, status = false or metrics = false to disable that service, or set individual api, ui and metrics flags. HTTP service changes apply live; moving or disabling this admin service disconnects this console. TCP listener changes require a restart.

The status service serves JSON at /status and Prometheus text at /metrics. A separate metrics server can be configured with metrics = "127.0.0.1:9091". Non-loopback admin access requires a token of at least 16 characters.

Extend with Lua

on_http = function(req)
    if req.path == "/ext/hello" then
        return {
            status = 200,
            content_type = "text/plain",
            body = "Hello from Rift!",
        }
    end
    -- Return nil for a 404 response.
end,

Requests include method, path, query, body, headers and a status snapshot at context. Routes under /ext/ use admin authentication and work independently of the built-in API flag.
